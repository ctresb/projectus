# Marketing site — UI kit

A pixel-leaning recreation of what `zenship.dev` should look like. Single-page landing, asymmetric, sumi-ink-on-paper, one pink accent. No screenshots, no gradient hero blobs, no testimonial wall.

## Files

- `index.html` — entry, mounts the page
- `Nav.jsx` — top nav (wordmark, links, install button)
- `Hero.jsx` — left-rail headline + terminal screencap on right
- `HowItWorks.jsx` — three steps, asymmetric, mono-numbered
- `Pricing.jsx` — two tiers (solo / team), no enterprise card, no fake discount
- `Footer.jsx` — minimal footer
- `app.jsx` — wires everything

## Source of truth

There is no source codebase or Figma — see project `README.md`. Visuals derive from `colors_and_type.css` and the brief.
